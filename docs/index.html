What it does

Core Features

A complete personal firewall prototype demonstrating key network security concepts in clean, modular Python.

📡

Live Packet Sniffing

Captures network packets in real time using Scapy. Extracts source IP, destination IP, protocol, and packet length.

🚫

IP Blocking

Persistent blocklist of individual IPs and CIDR ranges. Blocked packets are denied instantly and logged with timestamps.

⚙️

Rule Engine

Modular, extensible rule system supporting per-protocol, per-port, and per-IP filtering loaded from a JSON config.

🌐

Website Blocking

Redirects domains to localhost via the OS hosts file. Works on Windows and Linux without any browser extension.

📋

Traffic Logging

Structured log file with timestamps, source/destination, protocol, and allow/block decision for every packet.

🖥️

GUI Dashboard

Full tkinter desktop interface with live packet table, statistics panel, blocked IP management, and log viewer.

📊

Statistics Tracking

Running totals of packets inspected, allowed, and blocked, broken down by protocol with uptime counter.

⌨️

Full CLI Interface

10 CLI commands for managing IPs, websites, and interfaces — no need to edit config files by hand.

How it works

Architecture

Six focused modules, each with a single responsibility, wired together in main.py.

📡

PacketSniffer

Scapy sniff() on a background thread. Parses IP/TCP/UDP headers.

→
⚙️

FirewallRules

Evaluates each packet against the IP blocklist and custom rules in order.

→
📋

FirewallLogger

→
📊

Monitor

Keeps rolling packet history and running totals for the dashboard.

Get started

Installation

Runs on Windows, Linux, and macOS. Requires Python 3.9+ and administrator/root privileges for packet capture.

1

Clone the repository

git clone https://github.com/sitanshusingh01/SuperShield-Building-a-Custom-Personal-Firewall-using-Python.git cd SuperShield-Building-a-Custom-Personal-Firewall-using-Python
2

Create a virtual environment (recommended)

python -m venv venv source venv/bin/activate # Windows: venv\Scripts\activate
3

Install dependencies

pip install -r requirements.txt
4

Start the firewall (CLI or GUI)

sudo python main.py sniff --dashboard # Terminal dashboard sudo python main.py gui # Desktop GUI

On Windows, install Npcap before running Scapy. On Linux you may need sudo apt-get install libpcap-dev.

Desktop Interface

GUI Dashboard

Launch a full desktop interface with sudo python main.py gui. No browser required.
